# Source code

- Source: https://github.com/OTA-Tech-AI/Robotania-SDK/tree/v1.3.8
- Source archive: https://github.com/OTA-Tech-AI/Robotania-SDK/archive/refs/tags/v1.3.8.tar.gz

The preferred source is the TypeScript in `src/`, with build scripts in
`scripts/` and dependency versions in `pnpm-lock.yaml`. See `package.json`
for the build commands. Native builds run on their matching OS and CPU.

The SDK license is provided in `LICENSE`. Component notices are provided
in `THIRD_PARTY_NOTICES.md`. Both native CLIs print these notices with
`--license`, without loading wallet configuration or contacting a service.
